# Munchkin-like MVP

## План (MVP)
1. Скелет проекта: Vite + React + TypeScript, базовая структура, линт/формат.
2. Игровая логика: состояние, колоды, бой, автосейв.
3. Минимальный UI: экраны setup/стол/бой/рука/шмотки/лог.
4. Тесты логики и деплой через GitHub Pages.

## Описание
Минималистичный прототип hot-seat игры на 2–4 игроков в стиле "Munchkin-like" с нейтральными заглушками. Данные карт оригинальные, без использования официальных материалов.

## Возможности MVP
- 2–4 игрока на одном устройстве.
- Ход: открыть дверь, бой, добор сокровища, конец хода.
- Бой с монстром: сила игрока/монстра, помощь другого игрока, одноразовые карты, попытка сбежать.
- Автосейв в LocalStorage, кнопка сброса партии.
- Лог событий (до 50 записей).

## Быстрый старт
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

## Тесты
```bash
npm run test
```

## Линт/формат
```bash
npm run lint
npm run format
```

## Деплой на GitHub Pages
1. Включите GitHub Pages (Settings → Pages → Source: GitHub Actions).
2. Запушьте в репозиторий — workflow сам соберёт и опубликует сайт.
3. Если нужна кастомная база, поменяйте `base` в `vite.config.ts`.
